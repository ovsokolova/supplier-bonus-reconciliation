# Возможность 1: Извлечение условий (Contract Bonus Extraction)

**Требование**: система ДОЛЖНА извлекать структурированные бонусные условия из сканов договоров, PDF и Excel-приложений.

## Сценарий: извлечение бонусных условий из PDF-договора

- **КОГДА** пользователь загружает PDF-договор поставщика с бонусным приложением
- **ТОГДА** система ДОЛЖНА выдать структурированный JSON: `{bonus_type, base_metric, tiers: [{threshold, rate}], period, currency}`
- **И** каждое извлечённое поле ДОЛЖНО сопровождаться ссылкой на источник: номер страницы, фрагмент исходного текста, координаты bounding box.

## Сценарий: извлечение ступенчатого ретро-бонуса из Excel-приложения

- **КОГДА** пользователь загружает Excel-файл с многострочными ступенчатыми бонусами
- **ТОГДА** система ДОЛЖНА распознать заголовки и сопоставить их с логическими полями (бонус, порог, ставка, период)
- **И** при несовпадении заголовков с шаблоном по умолчанию система ДОЛЖНА выдать черновик сопоставления и запросить подтверждение пользователя, а не молча принимать первое совпадение.
