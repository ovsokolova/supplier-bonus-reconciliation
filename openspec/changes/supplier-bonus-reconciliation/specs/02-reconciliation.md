# Возможность 2: Сверка (Reconciliation Comparison)

**Требование**: система ДОЛЖНА сопоставлять извлечённые условия договора с фактическими данными ERP (объём закупок, сумма оплат, возвраты) и классифицировать каждую строку по категории.

## Сценарий: сопоставление внешним соединением

- **КОГДА** система одновременно загружает данные условий договора и фактические данные о закупках
- **ТОГДА** система ДОЛЖНА выполнить внешнее соединение (outer join) по измерению «поставщик + товар»
- **И** ДОЛЖНА классифицировать результат как: `matched`, `amount_mismatch`, `missing_in_actuals`, `missing_in_contract`, `period_offset`.

## Сценарий: допуск по сумме

- **КОГДА** разница между договорной и фактической суммой находится в пределах допуска (по умолчанию ±1 ₽, настраивается)
- **ТОГДА** система ДОЛЖНА пометить строку как `matched_within_tolerance`
- **И** ДОЛЖНА отобразить использованное значение допуска в отчёте.

## Сценарий: нормализация ключей сопоставления

- **КОГДА** система готовит данные к внешнему соединению
- **ТОГДА** система ДОЛЖНА выполнить нормализацию: приведение наименований к нижнему регистру, удаление организационно-правовых форм (ООО, АО, ПАО), кавычек, лишних пробелов и знаков препинания
- **И** ДОЛЖНА сохранить исходное значение в отдельном поле `*_raw` для отображения пользователю.

## Сценарий: нечёткое сопоставление при отсутствии точного совпадения

- **КОГДА** после нормализации точное совпадение по ключу не найдено
- **ТОГДА** система ДОЛЖНА применить нечёткое сопоставление (порог настраиваемый, по умолчанию 90 из 100)
- **И** при результате выше порога ДОЛЖНА пометить строку как `matched_fuzzy` с указанием коэффициента схожести и обоих исходных наименований
- **И** при результате ниже порога ДОЛЖНА пометить как `missing_in_actuals` и поместить в очередь `needs_review`.

## Сценарий: кандидаты для ручного выбора

- **КОГДА** для одной строки найдено несколько кандидатов выше порога
- **ТОГДА** система ДОЛЖНА вывести всех кандидатов с коэффициентами и запросить подтверждение пользователя, не выбирая автоматически.
