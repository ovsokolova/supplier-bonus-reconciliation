# ADR-003: LLM — только локально (Ollama)

**Статус**: принято

**Контекст**: договоры поставщиков содержат коммерческую
тайну: цены, объёмы, условия бонусов, реквизиты.
Использование внешних LLM-API создаёт риск утечки
и может противоречить политике ИБ компании.

**Решение**: по умолчанию использовать Ollama в контуре
компании. Внешний OpenAI-compatible API допускается только
при письменном согласовании службы ИБ и с обязательным
обезличиванием данных.

**Обоснование**:

- локальный инференс исключает передачу конфиденциальных
  данных третьим лицам;
- Ollama поддерживает модели, достаточные для
  структурированного извлечения по JSON Schema;
- отказ от внешних API упрощает ИБ-согласование
  и снижает юридические риски.

## Минимальные требования к оборудованию

| Модель | GPU | RAM | Контекст | Комментарий |
|---|---|---|---|---|
| qwen2.5:7b-instruct | 8 GB VRAM | 16 GB | 32k | Минимум для PoC |
| qwen2.5:14b-instruct | 16 GB VRAM | 32 GB | 32k | Рекомендуется |
| llama3.1:8b-instruct | 8 GB VRAM | 16 GB | 128k | Альтернатива |
| gpt-oss:20b (MoE) | 16 GB VRAM | 32 GB | 128k | Если есть GPU |

**Fallback без GPU**: CPU-инференс через llama.cpp —
время обработки одного договора возрастает с ~30 сек
до ~5–10 мин, что выходит за критерий успеха (≤3 мин).
Для PoC рекомендуется GPU с 8+ GB VRAM.

**Последствия**:

- плюсы: соответствие требованиям ИБ, нет зависимости
  от внешних сервисов;
- минусы: требования к локальному GPU/CPU;
  возможное снижение качества против топовых моделей;
- нейтрально: конфигурация модели — в переменных окружения;
  логи без содержимого.

**Альтернативы**:

- внешний OpenAI API: выше качество, но неприемлемо
  по требованиям ИБ без обезличивания;
- гибридный подход: локально для конфиденциальных,
  внешний — для обезличенных; рассматривается
  как расширение после PoC.

## Фактическая модель и параметры

На момент реализации PoC:

- **Модель по умолчанию:** `qwen2.5:7b-instruct`
  (из `LLM_MODEL` в `.env`);
- **Vision-модель:** `qwen2.5-vl:7b` (из `LLM_VISION_MODEL`);
- **Ollama URL:** `http://localhost:11434` (из `OLLAMA_BASE_URL`);
- **Требования к оборудованию:** 8 GB VRAM, 16 GB RAM.

Альтернативные модели, проверенные на совместимость:

- `mistral:7b-instruct-q4_K_M` — приемлемое качество, чуть хуже на русском;
- `llama3.2:3b` — быстрее, ниже качество на сложных договорах.

Модели `qwen2.5-coder:*` **не используются** — они оптимизированы
под код, а не под извлечение данных из естественно-языковых документов.
