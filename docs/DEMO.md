# Сценарий демонстрации PoC

**Длительность:** 10–15 минут
**Аудитория:** финансовый директор, руководитель ИТ, CPO

## Подготовка

```powershell
.venv\Scripts\Activate.ps1
dir data\examples\contracts
streamlit run src/supplier_bonus/ui/app.py
```

Открыть http://localhost:8501

## Ход демонстрации

### 1. Введение (1 мин)

> «Сейчас сверка бонусов с поставщиками — ручная работа: 8–20 часов в месяц. PoC делает это за минуты».

### 2. Проблема (1 мин)

> «Три источника: PDF-договор, Excel-приложение, выгрузка из ERP. Расхождения находятся поздно, деньги теряются».

### 3. Решение (7 мин)

**Шаг 1.** Sidebar: amount_tolerance = 1 руб., fuzzy_threshold = 90.

**Шаг 2.** Нажать «Загрузить демо-фикстуры» — подтягиваются 20 договоров.

**Шаг 3.** Нажать «Запустить сверку».

**Шаг 4.** Показать KPI: Совпало 14, Нечётко 2, Расхождение 4, Пропуски 4.

**Шаг 5.** Таблица с подсветкой: зелёный — совпало, жёлтый — fuzzy, красный — расхождение.

**Шаг 6.** Фильтр по статусам — выбрать только amount_mismatch.

**Шаг 7.** Нажать «Скачать Excel» — открыть три листа.

**Шаг 8.** Секция «Черновик претензии»: выбрать поставщика, период, скачать.

### 4. Что не показано, но есть (2 мин)

**CLI:**

```bash
python -m supplier_bonus reconcile contracts.csv actuals.csv --out report.xlsx
```

**Excel-отчёт:** три листа с подсветкой.

**Извлечение из PDF:** OCR + локальная LLM (qwen2.5:7b-instruct).

### 5. Следующие шаги (2 мин)

1. Интеграция с Ollama — end-to-end на реальных PDF.
2. Валидация на 20+ реальных договорах.
3. Подсветка источника в PDF.
4. Миграция на FastAPI + React.

### 6. Вопросы

**Сколько сэкономит?** — 8–20 часов в месяц + 2–3 % от суммы бонусов за счёт выявленных расхождений.

**Безопасно?** — LLM работает локально (Ollama). Данные не покидают контур компании.

**Что дальше?** — 2–3 недели на end-to-end с Ollama и валидацию, затем MVP.

## Резервный план (если UI не запускается)

```bash
python -m supplier_bonus reconcile data/examples/contracts.csv data/examples/actuals.csv --out demo.xlsx
```

Открыть `demo.xlsx` — те же три листа.
